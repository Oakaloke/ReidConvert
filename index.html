How it works & FAQ
  • Private by design. Everything runs in your browser using JavaScript and the HTML canvas. No image is ever sent to a server.
  • HEIC / HEIF (the format iPhones use) is decoded in-browser with the open-source heic2any library. Live Photos or bursts that contain multiple frames are each exported separately.
  • Quality slider applies to JPG and WEBP output. PNG is lossless, so the slider is hidden for it.
  • Nothing installs. It's just a web page — bookmark it and use it offline-friendly on phone or desktop.
